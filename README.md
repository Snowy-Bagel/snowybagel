# Snowy Bagel

Marketing site for [Snowy Bagel](https://www.snowybagel.com), a tiny app studio. Built with Astro, deployed on Vercel.

```sh
npm install
npm run dev
npm run build
```

## Layout

- `src/data/site.ts` — all copy, projects, and links
- `src/components/Mark.astro` — the logo mark (also `public/favicon.svg`)
- `src/components/Home.astro` — the homepage
- `src/layouts/Base.astro` — document head, metadata, and CSS reset
